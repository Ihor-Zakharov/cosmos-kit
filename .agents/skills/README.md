# Навыки проекта

Навык — папка `<имя>/` с файлом `SKILL.md`. Формат одинаков для Claude Code и Antigravity,
поэтому каталог общий: `.claude/skills` — симлинк сюда.

```
.agents/skills/
└── deploy-staging/
    ├── SKILL.md        # обязательный, с фронтматтером
    ├── scripts/        # необязательно
    └── references/     # необязательно: объёмная документация
```

`SKILL.md`:

```markdown
---
name: deploy-staging
description: >-
  Когда агенту это применять, в третьем лице.
  Например: "Использовать, когда пользователь просит выкатить ветку на staging."
---

# Деплой на staging

## Шаги

1. Проверить, что тесты зелёные: `npm test`
2. Запустить `./scripts/deploy.sh staging`
3. Убедиться, что healthcheck отвечает 200.
```

Оба агента грузят навык не целиком: в контекст попадают только `name` и `description`,
полный текст — когда навык реально понадобился. Поэтому `SKILL.md` держи коротким,
а объёмное выноси в `references/`.
