# Сайт в стиле cosmos-kit

## Что это и когда применять

cosmos-kit (`~/projects/cosmos-kit`) — переиспользуемый дизайн-кит: токены, фон-сцена «чёрная
дыра», пружинная физика и набор компонентов, обобщённые из проекта «выдра». Применяйте этот
навык, когда делаете новый сайт (или раздел существующего) в том же визуальном языке.

Это ТОЛЬКО тёмная тема с монохромными поверхностями. Если задача требует светлой темы или
принципиально другой композиции — это дизайнерское решение, которого кит сознательно не
принимает (см. `~/projects/cosmos-kit/DESIGN-TODO.md`); остановитесь и уточните у пользователя,
а не изобретайте светлую тему на ходу.

## Как подключить кит

1. Скопируйте (не симлинком — сайт должен быть самостоятельным репозиторием) в проект сайта:
   - `src/css/tokens.css`, `src/css/components.css`
   - `src/js/cosmos.js`, `src/js/motion.js`
   - `src/fonts/` (все `.woff2` + `fonts.css`)
   - `src/icons/sprite.svg`
   - `src/scene/plate.webp` (только если используете фон-сцену)
2. В `<head>` — в этом порядке: `fonts.css` → `tokens.css` → `components.css` → свои
   специфичные для сайта CSS (навигация, разделы — их кит не даёт, см. DESIGN-TODO §3).
3. `<html data-theme="dark">` — тема фиксирована.
4. Для фона: разметка-минимум
   ```html
   <div class="cosmos-wrap" id="cosmos-wrap" aria-hidden="true">
     <canvas class="cosmos" id="cosmos"></canvas>
     <div class="cosmos-fallback"></div>
     <div class="grain"></div>
   </div>
   ```
   и в модуле:
   ```js
   import { createCosmos } from './src/js/cosmos.js';
   const api = createCosmos(document.getElementById('cosmos'),
     { reduced: matchMedia('(prefers-reduced-motion: reduce)').matches });
   new ResizeObserver(() => api.resize()).observe(document.getElementById('cosmos-wrap'));
   ```
   Позиционирование `.cosmos-wrap` (fixed на весь экран или в рамках одной секции, поведение при
   скролле) сайт задаёт сам — кит не навязывает многоэкранную структуру «выдры» (DESIGN-TODO §6).
5. Для интерактивных эффектов (свет курсора, press-пружины, сегментные плашки вкладок):
   ```js
   import { pressable, attachPointerGlow, moveInk, enter } from './src/js/motion.js';
   attachPointerGlow(document, '.glass, .field-body');
   pressable(document, '.btn, .chip-btn, .icon-btn, .tab, .pills button, .card', { scale: 0.97 });
   ```

## Какие токены и компоненты брать

- **Цвет.** Только `--el-a`/`--el-b` (излучение) красятся под смысл сайта. Все остальные
  поверхности (`--s1`…`--s4`, `--ink*`, `--line*`) остаются монохромными — это правило языка,
  не нарушайте его точечной подкраской карточек/фонов.
- **Акценты.** `data-accent="a|b|c|d"` в `tokens.css` — только ПРИМЕР механизма (унаследован от
  цветов платформ «выдры»). Для нового сайта придумайте свою ось и цвета — это дизайнерское
  решение, зафиксируйте его в `DESIGN-TODO.md` кита или в документации самого сайта, не молчком.
- **Компоненты** — берите из `components.css` как есть по классам: `.btn`/`.chip-btn`/`.icon-btn`,
  `.field` (поле ввода с каймой), `.tabs`/`.pills` + `.tab-ink`/`.pill-ink`, `.switch`, `.card`,
  `.tree-nav`/`.tnode`, `.crumbs`/`.crumb`, `.tag`/`.chip`, `.pager`, `.meter` (прогресс),
  `dialog`/`.drawer`/`.modal`/`.card-block`, `.toasts`/`.toast`, `.ctx`, `.empty`/`.skel`.
  Смотрите `demo/index.html` кита — это живой каталог всех классов с примерами разметки.
- **Не изобретайте новые классы поверх существующих имён** — если нужного компонента нет,
  либо собирайте его из токенов (цвет/радиус/тень/шрифт уже заданы), либо явно проектируйте
  новый и добавляйте в кит отдельным проходом (не тихой правкой под конкретный сайт).

## Правила

- Тёмная тема — чёрная дыра. Светлая — не сейчас (см. выше).
- Монохромные поверхности, цвет только в излучении (`--el-a`/`--el-b`) — ни одна плита, карточка
  или фон не красится напрямую в акцентный цвет; только рамки/иконки/полоски свечения.
- Одно «раскалённое» (сильное свечение, `--white-glow`) действие на экран — обычно `.btn.primary`
  или `.go-btn`. Не делайте два одинаково ярких элемента одновременно — это разрушает иерархию.
- `prefers-reduced-motion: reduce` уважается везде из коробки (tokens.css/components.css/motion.js
  сами это делают) — не отключайте эти правила и не забывайте протестировать с включённой опцией.
- Русские комментарии в коде кита — сохраняйте стиль при добавлении своего кода рядом.

## Чек-лист перед сдачей

- [ ] Нет горизонтальной прокрутки страницы ни на одном брейкпоинте (`overflow-x: hidden` уже
      в `tokens.css` на body, но проверьте контент — длинные строки, широкие таблицы/картинки).
- [ ] На мобильном (≤ 680px) — гаттеры по бокам не меньше 16px.
- [ ] `prefers-reduced-motion: reduce` — включите в devtools (Rendering → Emulate CSS media
      feature) и проверьте: сцена не крутится/не выезжает, спрайты каймы/пружины не дёргаются.
- [ ] Производительность фона: `cosmos.js` рисует в холст с `resScale` (по умолчанию 0.5 от CSS px,
      dpr ограничен 1, кап 1.1 Мпикс) — не поднимайте `resScale` без проверки на слабом железе;
      сцена сама снижает детализацию при затянутых кадрах (`_lite`), не боритесь с этим вручную.
- [ ] Консоль браузера чиста при загрузке страницы (нет 404 на шрифты/иконки/scene/plate.webp,
      нет ошибок WebGL-компиляции — при их отсутствии сцена сама показывает `.cosmos-fallback`,
      это нормальный деградированный режим, а не баг).
- [ ] Все акцентные цвета и любая новая композиция явно согласованы (см. «Правила» выше), а не
      придуманы по ходу реализации.
