# cosmos-kit

## Что это

Переиспользуемый дизайн-кит визуального языка «чёрная дыра» (KOCMOC/UNLEASHED): тёмная тема,
монохромные поверхности, цвет только в излучении. Вынесен и обобщён из проекта «выдра»
(`~/projects/video-downloader`, фронтенд в `vydra/static/`), чтобы делать другие сайты в том же
стиле без копипасты и без логики выдры. Плоский набор статических файлов — не npm-пакет,
не фреймворк, никакой сборки не требует.

## Команды

- установка: нет (статика, ничего не собирается)
- запуск демо: `python3 -m http.server` из корня проекта, затем открыть `http://localhost:8000/demo/`
- тесты: нет автоматических; проверка демо — вручную в браузере (консоль без ошибок) или
  headless-браузером, если он доступен в окружении (Playwright требует системных библиотек
  `libnspr4`/`libnss3` — на этой машине их нет и `sudo apt install` не поставить неинтерактивно;
  при живой проверке — просто открыть `demo/index.html` и посмотреть в devtools)

## Структура

- `src/css/tokens.css` — все переменные (цвета, радиусы, тени, `--el-*` излучение, шрифты, тайминги)
  + база (сброс, фокус, зерно, reduced motion). Подключать первым.
- `src/css/components.css` — компоненты без логики конкретного сайта: кнопки, поле ввода
  (`.field`), вкладки/пилюли, переключатель, карточки, дерево, крошки, теги/чипы, пейджер,
  индикатор прогресса, диалоги/шторки/модалки, тосты, контекстное меню, пустое состояние;
  плюс обёртка сцены (`.cosmos-wrap`: состояния `.past`/`.asleep`, композиции `data-comp`),
  навигация (`.topbar`, `.island`) и каркас страницы (`.hero`, `.section`, `.site-footer`).
- `src/js/cosmos.js` — фон «чёрная дыра» (WebGL-шейдер), самодостаточный модуль:
  `createCosmos(canvas, opts)` / алиас `init(canvas, opts)`; `attachSceneScroll(api, {hero, wrap})` —
  поведение при прокрутке.
- `src/js/motion.js` — пружинная физика (`Spring`, `Motion`, `enter`/`exit`, `pressable`, `flip`)
  + хелперы `attachPointerGlow`, `moveInk`, `attachSwipeToClose`.
- `src/fonts/` — Geologica, Onest, Unbounded, JetBrains Mono (Google Fonts, OFL) + `fonts.css`.
- `src/icons/sprite.svg` — общие UI-глифы (без брендов платформ).
- `src/scene/plate.webp` — текстура дальнего плана для сцены чёрной дыры.
- `demo/index.html` — витрина всего кита живьём.
- `.agents/skills/cosmos-site/SKILL.md` — воркфлоу «сделать новый сайт в этом стиле».
- `DESIGN-TODO.md` — журнал дизайнерских решений: что решено (и где искать), что отложено
  (светлая тема), что открыто.

## Соглашения

- Дизайнерские решения принимаются только дизайнерским проходом и записываются в `DESIGN-TODO.md`
  (решено/отложено/открыто) — не по ходу реализации. Ось акцентов, поведение сцены, навигация и
  правила композиции (SKILL.md «Композиция и тон») — уже решены; менять их — новый пункт журнала.
- Обновление токенов/компонентов из «выдры»: смотреть в исходный файл в
  `~/projects/video-downloader/vydra/static/...` (пути перечислены в комментариях наверху каждого
  файла кита), переносить точечно, не расширяя вкус — если правка в выдре добавляет новый цвет
  или новую композицию, это тоже уходит в `DESIGN-TODO.md`, а не копируется молча.
- Названия классов обобщены (например `.portal` → `.field`, `--bh-*` на `.cosmos-wrap` остаются
  как есть — это публичный API сцены).
- Комментарии в коде — на русском, как в источнике.

## Ограничения

- Не коммить секреты (.env, ключи, токены) — в этом проекте их не предполагается.
- Не трогать `~/projects/video-downloader` — только чтение оттуда, там параллельно работает
  другой агент.
- Не принимать новых дизайнерских решений «по вкусу» без явной просьбы — записывать в
  `DESIGN-TODO.md`. Светлую тему не трогать до отдельной просьбы пользователя.
