# cosmos-kit

## Что это

Переиспользуемый дизайн-кит визуального языка «чёрная дыра» (KOCMOC/UNLEASHED): тёмная тема,
монохромные поверхности, цвет только в излучении. Вынесен и обобщён из проекта «выдра»
(`~/projects/video-downloader`, фронтенд в `vydra/static/`), чтобы делать другие сайты в том же
стиле без копипасты и без логики выдры. Плоский набор статических файлов — не npm-пакет,
не фреймворк, никакой сборки не требует.

## Команды

- установка: нет (статика, ничего не собирается)
- запуск демо: `python3 -m http.server` из корня проекта, затем открыть `http://localhost:8000/demo/`
- тесты: `sh selftest.sh` — блоки и заготовка проходят свой линтер, `cosmos.py init` собирает сайт и приложение,
  браузерная проверка (`src/tools/shot.mjs`: Node ≥ 22 + любой Chrome; из WSL сам находит Windows Chrome) без ошибок.
  Перед каждым коммитом правок в `src/`, `starter/`, `global/`.

## Структура

- `src/css/tokens.css` — все переменные (цвета, радиусы, тени, `--el-*` излучение, шрифты, тайминги)
  + база (сброс, фокус, зерно, reduced motion). Подключать первым.
- `src/css/components.css` — компоненты без логики конкретного сайта: кнопки, поле ввода
  (`.field`), вкладки/пилюли, переключатель, карточки, дерево, крошки, теги/чипы, пейджер,
  индикатор прогресса, диалоги/шторки/модалки, тосты, контекстное меню, пустое состояние;
  плюс обёртка сцены (`.cosmos-wrap`: состояния `.past`/`.asleep`, композиции `data-comp`),
  навигация (`.topbar`, `.island`) и каркас страницы (`.hero`, `.section`, `.site-footer`).
- `src/js/cosmos.js` — фон «чёрная дыра» (WebGL-шейдер), самодостаточный модуль:
  `createCosmos(canvas, opts)` / алиас `init(canvas, opts)`; `attachSceneScroll(api, {hero, wrap})` —
  поведение при прокрутке.
- `src/js/motion.js` — пружинная физика (`Spring`, `Motion`, `enter`/`exit`, `flip`) + механика интерфейса:
  `attachButtons`, `buttonState`, `attachSwitches`, `attachChecks`, `attachDisclosures`, `attachCards`,
  `openDialog`/`closeDialog`, `pushToast`, `countTo`/`odometer`, `moveInk` («капля»), `attachPointerGlow`, `attachSwipeToClose`.
- `src/css/kosmos.css` + `src/js/kosmos.js` — необязательные: три компонента по мотивам KOCMOC (глифы, пульс, HUD).
- `src/fonts/` — Geologica, Onest, Unbounded, JetBrains Mono (Google Fonts, OFL) + `fonts.css`.
- `src/icons/sprite.svg` — общие UI-глифы (без брендов платформ).
- `src/scene/plate.webp` — текстура дальнего плана для сцены чёрной дыры.
- `demo/index.html` — витрина, одна страница: сайт, каталог, «Движение» (живые образцы с параметрами пружин),
  KOCMOC, сцена; общие `demo.css`/`demo.js`.
- `src/tools/` — ИИ-воркфлоу (едет в проект как `kit/tools/`): `cosmos.py` (init/status/done/setup/update/hook,
  global-install, quiz, selfcheck), `check.py` (линтер правил кодами; `--classes/--tokens/--icons/--rules`), `shot.mjs`
  (браузерная проверка: 2560/1920/390, B1–B12, `--palette`), `contrast.py` (APCA), `agent-quiz.md` (экзамен для модели).
- `src/blocks/` — готовые блоки разметки + `INDEX.md`; каждый блок обязан проходить `check.py --self`.
- `src/agent/` — навык `skills/cosmos-site` (SKILL.md — короткий цикл, `references/` — подробности), агенты
  `agents/cosmos-eyes.md`, `cosmos-critic.md`, `AGENTS-block.md` (блок правил, который `init` вставляет в AGENTS.md проекта).
  `.agents/skills/cosmos-site` — ссылка сюда.
- `global/cosmos-ui/SKILL.md` — глобальный навык «примени UI» (ставит `install.sh` / `install.ps1`, там же глобальный хук).
- `AGENT.md` — вход для ИИ по ссылке на репозиторий: install → init → навык. `GUIDE.md` — для людей (Antigravity).
- `DESIGN-TODO.md` — журнал дизайнерских решений: что решено (и где искать), что отложено
  (светлая тема), что открыто.

## Соглашения

- ИИ-воркфлоу держит качество механикой: правило, которое можно проверить машиной, добавляется в `check.py`
  (или `shot.mjs`) с кодом и подсказкой «→ как исправить», а в SKILL.md — одной строкой с тем же кодом. Прозу в навыке
  не раздувать: SKILL.md — до ~140 строк (включая два топ-10), остальное — `references/`. Проверять на слабой модели:
  `claude -p "…" --model haiku --effort low` в пустой папке и экзаменом `python3 src/tools/cosmos.py quiz` (10 типовых ошибок).
- Правила против забывания: топ-10 живёт в `src/agent/TOP.md` и вставлен слово в слово (между `<!-- cosmos-top:begin/end -->`)
  сверху и в конце `AGENT.md`, `src/agent/AGENTS-block.md` (там пути `{kit}/`), `SKILL.md`, `global/cosmos-ui/SKILL.md`; меняется
  только TOP.md, копии правятся следом, расхождение валит `cosmos.py selfcheck` (в `selftest.sh`). Каждое правило — «делай X»
  с числом или примером и кодом линтера; расплывчатых формулировок («аккуратно», «по возможности») не писать. Один источник
  правды на тему: пороги — `UX.md` (`references/ux.md` — та же копия байт в байт, selfcheck сверяет), опыт — `lessons.md`, цикл — `SKILL.md`.

- Дизайнерские решения принимаются только дизайнерским проходом и записываются в `DESIGN-TODO.md`
  (решено/отложено/открыто) — не по ходу реализации. Ось акцентов, поведение сцены, навигация и
  правила композиции (SKILL.md «Композиция и тон») — уже решены; менять их — новый пункт журнала.
- Обновление токенов/компонентов из «выдры»: смотреть в исходный файл в
  `~/projects/video-downloader/vydra/static/...` (пути перечислены в комментариях наверху каждого
  файла кита), переносить точечно, не расширяя вкус — если правка в выдре добавляет новый цвет
  или новую композицию, это тоже уходит в `DESIGN-TODO.md`, а не копируется молча.
- Названия классов обобщены (например `.portal` → `.field`, `--bh-*` на `.cosmos-wrap` остаются
  как есть — это публичный API сцены).
- Комментарии в коде — на русском, как в источнике.

## Ограничения

- Не коммить секреты (.env, ключи, токены) — в этом проекте их не предполагается.
- Не трогать `~/projects/video-downloader` — только чтение оттуда, там параллельно работает
  другой агент.
- Не принимать новых дизайнерских решений «по вкусу» без явной просьбы — записывать в
  `DESIGN-TODO.md`. Светлую тему не трогать до отдельной просьбы пользователя.

## Версии

Кит развивается дальше. Любая правка в `src/` сопровождается записью в раздел «Не выпущено» в `CHANGELOG.md`;
переименование или удаление класса, токена, JS-функции помечается **ломает**. Выпуск версии — только по просьбе
пользователя: перенести записи под новую версию, обновить `VERSION`, коммит, тег `vX.Y.Z`, push с тегами.
