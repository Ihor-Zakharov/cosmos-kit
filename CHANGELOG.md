# Изменения

Формат: версия — дата — что изменилось. Изменения, требующие правок в подключивших кит сайтах, помечены **ломает**.

## Не выпущено

### Движение (проход «анимации уровня Apple»)

- `motion.js`: `attachButtons()` — единая механика кнопок: нажатие на пружине, следующее за пальцем (вниз мгновенно,
  отпускание с одним мягким перелётом, увод указателя — отмена без отскока), подъём при наведении (только мышь),
  без магнита (**ломает**: атрибут `[data-magnetic]` из промежуточной правки удалён и больше не работает — кнопки и плиты
  за курсором не двигаются, решение пользователя), Space/Enter нажимают так же,
  фокус с клавиатуры — короткий «вдох». `pressable()` оставлен для совместимости, новым сайтам нужен `attachButtons()`.
- `motion.js`: `buttonState(el, 'idle' | 'busy' | 'done')` — смена состояний кнопки без скачка ширины; CSS `.btn-label`,
  `.btn-fx`, `.btn-spin`, `.btn-check` в `components.css`.
- `motion.js`: `moveInk()` теперь едет пружиной и «каплей» (две кромки на своих пружинах: ведущая .26, ведомая .42),
  поддерживает ось y (`.tree-ink`, подсветка текущей строки дерева переезжает, как в «выдре») и `.nav-ink`
  (полоска активного пункта в шапке). Раньше плашка прыгала без анимации.
- `motion.js`: `attachSwitches()` (ползунок-«капля»), `attachChecks()` (новые `.check`/`.radio` в `components.css`),
  `attachDisclosures()` (новый `.disclosure`), `attachCards()` (наклон к курсору и подъём), `openDialog()`/`closeDialog()`
  (плита въезжает и уходит; закрытие после ухода, Esc так же), `pushToast()`/`dismissToast()`, `countTo()` и `odometer()`
  (новый `.odometer`); `enter()`/`exit()` принимают `dx`; `Motion` умеет `rx`/`ry` (rotateX/Y с perspective).
- `components.css`: свет курсора по поверхности — только у `.btn[data-glow]`/`.chip-btn[data-glow]`/`.card[data-glow]`
  (правило «1–3 элемента на экран»). **Ломает**: селектор по умолчанию `attachPointerGlow()` сменился с
  `.glass, .field-body` на `.field-body, [data-glow]` — `.glass`-плиты больше не получают `--mx/--my` (CSS их и не
  использовал); кто передавал свой селектор — не задет.
- `components.css`: у дерева с `.tree-ink` и у «линии» с `.nav-ink` фон и `:hover` текущего пункта прозрачны
  (и без задержки перехода) — плашка одна на всё дерево, во время переезда второй не появляется (как в «выдре»).
- `components.css`: `.section > * { margin-inline: auto }` — блоки с `max-width` внутри секции центрирует каркас
  (раньше вставали слева, что нарушало правило «всё по центру»).
- Отметка выбора и перетаскивания — монохромная: `.card.selected` — поверхность `--s3`, `.card.drop-target`/`.tnode`/
  `.crumb.drop-target` — кайма `--line-3`; токены `--el-mark`/`--el-mark-glow` из промежуточной правки удалены — **ломает**,
  если кто-то успел на них сослаться. Hover карточки — совсем слабая виньетка, привязанная к курсору (центр
  прозрачен и следует за указателем, к краям темнеет на 16 %), кайма и фон не меняются; `attachPointerGlow` по умолчанию `.field-body, .card, [data-glow]` (**ломает**
  тех, кто полагался на промежуточное умолчание `.field-body, [data-glow]`).
- `components.css`: у `.switch` убрано
  правило `:active { width: 17px }` — ширину ползунка теперь ведёт пружина (transform), не layout.
- `tokens.css`: `:focus-visible` — offset 3px и переход кольца.
- `.disclosure-head`: симметричные поля 14px, hover-плашка шириной с разделители, по клику мышью кольца нет (`:focus:not(:focus-visible)`), маркер `<summary>` скрыт.
- `.btn.primary`/`.go-btn`: при наведении свечение не растёт (остаётся как в покое) — только подъём; решение пользователя.
- **Правила движения в SKILL.md пересмотрены** (раздел «Движение»): основа прежняя (четыре длительности, пружины
  для всего, что следует за пальцем, ничего не зациклено), добавлены: словарь пружин по ситуациям (нажатие/отпускание/
  капля/появление/числа), «один индикатор активного состояния на элемент», пульс «в такт» как приём для событий,
  переходы диалогов. Числа `--t-*` и easing НЕ менялись — подключённые сайты не задеты.

### Сцена

- `cosmos.js`: `SMOKE` и `api.setSmoke(name)` — пять лёгких оттенков дыма (cold, moon, warm, violet, ember; amt 0.22–0.45)
  поверх `setAccent(hex, amt)`; приём «сцена отражает процесс» (`pulse('go')` → `setEnergy(1)` → `setEnergy(0)` +
  `pulse('done')`, как загрузка в «выдре») описан в SKILL.md «Сцена и процесс». В демо — кнопка «Крутить» и ряд «Дым».
- `cosmos.js`: варианты ореола и лучей — `createCosmos(canvas, { halo: 'calm' | 'chaotic', rays: false | true })`,
  живая смена `api.setHalo()`/`api.setRays()`; по умолчанию calm без лучей = прежний вид. «Хаотичный» — неровная яркость
  по окружности, дрожь кромки (±1 % R), шире радужная кайма, живее нити; «лучи RTX» — рассеяние кольца в дымке
  перераспределяется в тонкие радиальные лучи (множитель со средним 1). Замер на 1440×900 (reduced, статичный кадр):
  средняя яркость кадра 31.8 / 31.6 / 31.6 / 31.4 (calm, chaotic, calm+rays, chaotic+rays), обод 0.9–1.3 R 174.5 / 173.8 /
  174.1 / 173.3 — хаос и лучи света не прибавляют. Время кадра в headless Edge (software D3D11): медиана 50 мс во всех
  четырёх — разницы нет; на GPU добавка — две fbm-выборки на пиксель, ожидаемо < 5 %.
- `cosmos.js`: опция `ringBrightness` (по умолчанию **0.88**, `1.0` = пиксель в пиксель как в v0.1.0) и CSS-токен `--bh-ring`
  — яркость первого ореола (раскалённый пояс у кромки тени и фотонное кольцо) в экранных значениях; внешнее гало, диск,
  плоскость и звёзды не задеты. Замер на 1440×900: обод 0.9–1.05 R темнее на 10–12 %, от 1.25 R — без изменений.

### KOCMOC (три компонента, `src/css/kosmos.css` + `src/js/kosmos.js`, необязательные)

- Линейные глифы со светом линии (`.glyph`, символы `k-*` в спрайте, `.spikes`), пульс «в такт» (`pulse()`),
  HUD-панель (`.hud`: рамка с уголками, развёртка, терминальный список, кольцо-индикатор; `hudRing()`, `hudType()`).
  Остальные идеи уровня отклонены — `DESIGN-TODO.md` §10.
- `tokens.css`: `data-accent` работает на любом элементе, не только на `<html>` (поддерево красится своей ступенью);
  `:root[data-accent]` по-прежнему работает.

### Композиция

- `components.css`: правило «всё по центру, кроме героя» — `.section-head` центрирован по умолчанию (`.left` — исключение),
  `.prose` центрирован как колонка, подвал центрирован; новые `.centered`, `.row-center`. **Ломает** визуально, не API:
  у подключивших сайтов головы секций и подвал станут центрированными (верните `.section-head.left`, если нужно слева).
- `.island`: убрано подчёркивание активной вкладки — плашка `.tab-ink` уже показывает активную; полоска излучения только у
  «линии» `.topbar .nav`. Правило «один индикатор активного состояния» — в SKILL.md.
- Правило красных кнопок (SKILL.md): `.btn.solid.danger` — только внутри подтверждения необратимого действия, не в общем
  ряду; в демо перенесена в модалку подтверждения.
- Демо — одна страница `index.html`: сайт + каталог + секция «Движение» (`#motion`, живые образцы с параметрами
  пружин) + KOCMOC (`#kosmos`) + сцена; общие `demo.css`/`demo.js`. Тяжёлые образцы (такт, числа) стартуют только
  в видимой области (IntersectionObserver).

## 0.1.0 — 2026-09-26

Первая версия.

- Вынесено из «выдры»: токены тёмной темы, шрифты (Geologica, Onest, Unbounded, JetBrains Mono — SIL OFL 1.1),
  иконки-спрайт, фон-сцена «чёрная дыра» (`cosmos.js`), пружинная физика и эффекты (`motion.js`),
  базовые компоненты (`components.css`).
- Ось акцентов «температура излучения»: `data-accent="violet|ice|white|gold|ember"`.
- Сцена при прокрутке: состояния «живая» / «за горизонтом» (`.past`) / «спит» (`.asleep`), `attachSceneScroll()`;
  композиции `data-comp="right|center|far"`.
- Навигация «линия» (`.topbar`) и «остров» (`.island`), каркас страницы (`.hero`, `.section`, `.site-footer`…).
- Витрина `demo/` — целый сайт + каталог компонентов; навык `cosmos-site` с правилами композиции и тона.
- Светлая тема — черновик, не поддерживается до отдельного прохода.
