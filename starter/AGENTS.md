# Сайт на cosmos-kit

Этот сайт сделан на дизайн-ките cosmos-kit (https://github.com/Ihor-Zakharov/cosmos-kit): тёмная тема
«чёрная дыра», монохромные поверхности, цвет только в излучении, пружинная анимация.

## Перед любой работой
Прочитай `.agents/skills/cosmos-site/SKILL.md` — там правила композиции, тона и движения и чек-лист проверки.
В навыке пути кита записаны как `src/...` — в этом проекте кит лежит в `kit/` (`src/css/…` → `kit/css/…`).

## Устройство
- `index.html` — главная (герой с чёрной дырой), `page.html` — пример внутренней страницы (сцена спит).
  Новые страницы копируй с `page.html`.
- `kit/` — копия кита, версия в `kit/VERSION`. **Не правь файлы в `kit/`**: обновление кита их затрёт.
  Всё своё — в `site.css` (и при необходимости `site.js`), только на токенах кита (`var(--ink)`, `var(--el-a)` …).
- Запуск: `python3 -m http.server 8000` в корне → http://localhost:8000/ (модули не работают с `file://`).

## Как наполнять
1. Замени всё, что помечено `ЗАМЕНИТЬ`, и тексты-заглушки: бренд, заголовок, секции, подвал, `<title>`.
2. Секции собирай из того, что есть в ките (`.section`, `.section-head`, `.grid-3`, `.card`, `.prose`, кнопки,
   поля, вкладки). Витрина всех компонентов — `demo/index.html` в репозитории кита.
3. Не добавляй свои цвета, шрифты, тени и анимации в обход токенов. Не делай светлую тему.
4. Проверь по чек-листу из навыка: нет горизонтальной прокрутки на 390px, отступы 16px на телефоне,
   консоль без ошибок, `prefers-reduced-motion` работает.

## Обновить кит
`sh update-kit.sh [vX.Y.Z]` — заменяет `kit/` и навык свежей версией; перед этим прочитай `kit/CHANGELOG.md`
новой версии: записи с пометкой **ломает** требуют правок в `index.html`/`site.css`.
