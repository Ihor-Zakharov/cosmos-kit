# Название проекта

О чём этот сайт и для кого — одна-две строки (заполнить при первой задаче).

## Устройство

- `index.html` — главная, `page.html` — внутренняя страница (копировать для новых), `site.css` — свои стили на токенах кита.
- Запуск: `python3 -m http.server 8000` → http://localhost:8000/ (модули не работают с `file://`).
