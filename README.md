# cosmos-kit

Дизайн-кит визуального языка «чёрная дыра» (тёмная тема, монохромные поверхности, цвет только
в излучении). Вынесен и обобщён из фронтенда проекта «выдра»
(`~/projects/video-downloader/vydra/static/`) — см. таблицу источников ниже. Дизайнерский проход
09.2026 добавил то, чего в «выдре» не было и что нельзя было вынести: ось акцентов, поведение сцены
при прокрутке, навигацию, каркас страницы и правила композиции — журнал решений в `DESIGN-TODO.md`.

Демо: `python3 -m http.server` из корня, затем `http://localhost:8000/demo/`.

## Статус и версии

Кит в работе: текущая версия — **0.1.0** (файл `VERSION`), дальше он будет улучшаться. Пока версия 0.x,
имена классов, токенов и JS-API могут меняться между минорными версиями — каждое такое изменение
записывается в `CHANGELOG.md` с пометкой «ломает». Открытые вопросы и план — в `DESIGN-TODO.md`.

- Сайты подключают кит **зафиксированной версией** (тег `vX.Y.Z`): `git submodule add <url> vendor/cosmos-kit`
  и `git -C vendor/cosmos-kit checkout v0.1.0`, либо копия `src/` из тега. Обновление — осознанный шаг
  с чтением `CHANGELOG.md`, а не автоматический.
- Выпуск версии: правка → запись в `CHANGELOG.md` → `VERSION` → коммит → тег `vX.Y.Z` → push с тегами.

## Как обновлять кит из «выдры»

1. Смотреть diff интересующего файла в `~/projects/video-downloader/vydra/static/...`
   (только чтение — там может параллельно работать другой агент).
2. Переносить точечно: если правка меняет только структуру/поведение (не добавляет новый цвет
   или композицию) — переносить и обобщать по тому же принципу, что и здесь (убирать привязку
   к выдре: `.job-*`, `.pv-*`, `.tile-*`, платформенные классы и т.п. → генерические имена).
3. Если правка добавляет дизайнерское решение (новый цвет, новая композиция, новый приём) —
   НЕ копировать молча. Дописать пункт в `DESIGN-TODO.md` и оставить кит как есть до
   следующего дизайнерского прохода. Обратное тоже верно: решения кита (ось акцентов, состояния
   сцены, навигация) в «выдру» не переносятся автоматически — там своя структура.
4. Обновить демо (`demo/index.html`), если добавился новый компонент — она должна показывать
   всё, что есть в ките.

## Лицензии шрифтов

Все четыре шрифта — с Google Fonts, лицензия **SIL Open Font License 1.1** (свободное использование,
в том числе коммерческое, при условии сохранения лицензии при распространении самих файлов шрифта):

- **Geologica** — вариативный гротеск, витрина/заголовки (`--font-display`)
- **Unbounded** — дисплейный, бренд/логотип (`--font-brand`)
- **Onest** — текстовый гротеск (`--font-text`)
- **JetBrains Mono** — моноширинный, числа/метки/код (`--font-mono`)

При переносе в новый проект держите файлы `.woff2` рядом с `fonts.css` (пути в `@font-face`
относительные) и, если публикуете шрифты отдельно от кита, кладите вместе с ними текст лицензии
OFL (не включён в этот репозиторий — возьмите с [google/fonts](https://github.com/google/fonts)
или fonts.google.com при необходимости).

## Что не выносилось из «выдры» и почему

- **Экран/навигация верхнего уровня «выдры»** (`.topbar`, `.screens`, «остров» очереди, подвал) — заточены
  под её структуру (три экрана: ссылка/очередь/библиотека). Кит вместо этого получил собственную
  навигацию (две композиции: «линия» и «остров») и каркас страницы — спроектированы на дизайнерском
  проходе, см. `DESIGN-TODO.md` §3 и §9.
- **Карточки задач `.job-*` и превью `.pv-*` / плитки `.tile-*`** — специфика видео-загрузчика
  (кадр-плёнка, платформенные бейджи, превью-плеер). Обобщённый прогресс-бар вынесен как `.meter`,
  остальное — не переносилось: слишком предметно-специфично, обобщение потребовало бы придумывать
  новую композицию, а не выносить существующую.
- **Иконки платформ** (YouTube/TikTok/Instagram) — бренд-специфика, не универсальный UI-глиф.
- **Светлая тема** — в «выдре» отключена и не проверена. Токены перенесены как заготовка
  (`tokens.css`, `:root[data-theme="light"]`); отложена по решению пользователя (`DESIGN-TODO.md` §2).
- **Логика приложения** (`app.js`, `explorer.js`) — не переносилась вовсе: это бизнес-логика
  видео-загрузчика (очередь загрузок, файловый менеджер), а не визуальный язык.
