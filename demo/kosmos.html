kocmoc · три компонента

Свет принадлежит линии.

Из уровня KOCMOC (Geometry Dash, ремейк Neiro «RTX: ON») взято только то, что выглядит так, будто всегда было частью кита: линейные глифы, пульс в такт и HUD-панель. Цвет — только через data-accent.

1 · глифы

Линейные глифы

Тонкая белая линия и свет, который принадлежит ей, а не фону. Тот же штрих, что у UI-иконок кита; цвет света — ступень излучения.

.glyph / .small / .large / .dim / .spin; ряд шипов — .spikes.

2 · такт

Пульс «в такт»

Кольцо расходится из точки события и гаснет, ядро вздрагивает. Для прихода события и «живых» индикаторов — не для декора по таймеру.

кольцо s .6 → 2.4 · response .9 · damping 1; o → 0 · response 1.0 · ядро s 1.18 → 1 · response .5 · damping .55 · pulse(host)

3 · hud

HUD-панель

Финальный экран уровня, переведённый в монохром: рамка с уголками, тихая развёртка, терминальный список с отточиями, кольцо-индикатор с барабаном. Здесь — в «углях» через data-accent на самом блоке.
