движение

Всё, что двигается, — пружина.

Каждый образец живой: нажмите, наведите, переключите. Под ним — параметры пружины из motion.js: response — период в секундах (меньше — резче), damping — доля критического демпфирования (1 — без отскока).

Нажатие, подъём, магнит

Главное действие за курсором не двигается; магнит — только явный opt-in data-magnetic. Увод указателя во время нажатия — отмена без отскока.

вниз s .97 (иконки .90, крупные плиты .985) · response .09 · damping 1
отпускание response .36 · damping .68 — один лёгкий перелёт; отмена — damping 1
подъём s 1.02 (иконки 1.06) · response .34 · damping .72 — только мышь
магнит (только [data-magnetic]) сдвиг 18 % от смещения курсора, до 6px · response .40 · damping .80; возврат response .5 · damping .62
свет курсора — не у рядовых кнопок: только [data-glow], 1–3 элемента на экран · attachButtons()

Состояние без скачка ширины

Подпись остаётся в потоке (ширина заперта), поверх — спиннер, потом галочка рисует себя.

подпись уходит o 0 · y −6 · s .92 · response .30 · damping 1
спиннер/галочка s .8 → 1 · o 1 · response .40 · damping .72 (галочка .60)
галочка stroke-dashoffset 24 → 0 за .45 s --ease-out · buttonState(el, 'busy' | 'done' | 'idle')

Фокус с клавиатуры

Нажмите Tab: кольцо фокуса цвета излучения и короткий «вдох» кнопки. Space/Enter нажимают её так же, как палец.

вдох s 1.06 → 1 · response .45 · damping .60
кольцо outline 2px --el-a, offset 3px, тень --focus-ring за --t-base

Переключатель — капля

Ползунок растягивается по ходу движения и, доехав, собирается обратно; пока палец на нём — чуть шире.

переезд sx 1.45 → 1 · x 0 ↔ 14 · response .36 · damping .66
удержание sx 1.2 · response .16 · damping 1; отпускание response .30 · damping .70 · attachSwitches()

Сегменты и вкладки — капля

У плашки две кромки на своих пружинах: ведущая быстрее, ведомая догоняет — плашка перетекает, а не прыгает.

ведущая кромка response .26 · damping .84 · ведомая response .42 · damping .80
то же для полоски навигации в шапке (.nav-ink) · moveInk(group, el)

Раскрытие

Три CSS, два ES-модуля, четыре шрифта, спрайт и одна текстура. Никакой сборки.

Отложена: сначала устоится тёмный язык, потом «отпечаток» проектируется заново.

тело grid-template-rows 0fr → 1fr за --t-base --ease-out
шеврон r 0 → 90° · response .42 · damping .60 · содержимое y −8 → 0, o 0 → 1 · response .50 · damping .80 · attachDisclosures()

Модалка, шторка, тост

Плита въезжает и уходит тем же путём; диалог закрывается только после ухода. Esc — так же.

подложка opacity за --t-base · openDialog(), closeDialog(), pushToast()
