# Блоки cosmos-kit — готовая разметка

Страница собирается из блоков, а не рисуется с нуля. Порядок работы: выбрать блоки по таблице →
открыть только нужные файлы → вставить в страницу → заменить всё `ЗАМЕНИТЬ` содержимым → удалить комментарий-шапку блока.
Лишнее в блоке (третья карточка, цифры героя) удалять можно, добавлять новые классы — нет (своё — в `site.css` на токенах).

Пути в блоках — `kit/…` от корня сайта. Если кит подключён иначе (приложение: `/static/kit/…`) — замените префикс,
он записан в `cosmos.json` → `kit_url`.

## Сайт (лендинг, визитка, продукт)

| блок | когда | файл |
|---|---|---|
| topbar | шапка + меню-шторка, всегда (в заготовке уже есть) | `topbar.html` |
| hero | первый экран главной, один на сайт | `hero.html` |
| features | «что это даёт»: 3 или 6 карточек | `features.html` |
| steps | «как это работает»: 3 шага | `steps.html` |
| text | о нас, история, статья — длинный текст | `text.html` |
| stats | ряд чисел с подписями | `stats.html` |
| pricing | тарифы, 3 карточки | `pricing.html` |
| faq | вопросы и ответы | `faq.html` |
| cta | завершающий призыв перед подвалом | `cta.html` |
| contact | форма заявки | `contact.html` |
| footer | подвал, всегда | `footer.html` |

Типичная главная: hero → features → steps → pricing → faq → cta/contact → footer (5–7 секций, не больше).
Внутренняя страница — копия `page.html` заготовки (сцена спит): короткий заголовок страницы + блоки text/features/faq.

## Приложение (кабинет, админка, инструмент)

| блок | когда | файл |
|---|---|---|
| app-shell | каркас: рейка слева + экран | `app-shell.html` (целая страница — `app.html` заготовки) |
| list | список записей | `list.html` |
| table | таблица данных | `table.html` |
| form | настройки, форма в приложении | `form.html` |
| wizard | анкета/онбординг по шагам (≤ 7), сверху «две дороги» | `wizard.html` |
| wizard-text | вторая дорога в анкету: рассказать своими словами, ИИ раскладывает по полям | `wizard-text.html` |
| tabs | вкладки / переключатель режима | `tabs.html` |
| empty | пустое состояние | `empty.html` |
| dialog-confirm | подтверждение необратимого | `dialog-confirm.html` |
| dialog-rate | быстрая оценка 1–10 одним кликом с выходом в подробное («уже читал») | `dialog-rate.html` |
| dialog-report | жалоба / «что-то не так» на элемент — обратимо, не красное | `dialog-report.html` |
| chat | чат с консультантом: отдельный экран во всю высоту, разговоры слева (поиск — когда их больше шести), переименование, кнопка «вниз»; рейка приложения свёрнута (`.app.chatmode`) | `chat.html` |
| advice | строки-советы с реакциями и группой «нескачанное» | `advice.html` |
| stats | ряд чисел (KPI) на обзоре | `stats.html` (только `.kpis`) |

## Если блока нет

1. Найти класс: `python3 kit/tools/check.py --classes <слово>` (токены — `--tokens`, иконки — `--icons`).
2. Собрать из существующих: `.panel`, `.card.static`, `.grid-3`, `.cols`, `.btn-row`, `.chip`, `.tag`, `.meter`.
3. Своя раскладка — свой класс в `site.css`, только на токенах (`var(--s1)`, `var(--line-1)`, `var(--r-l)`, `var(--t-fast)`).
