## Интерфейс — cosmos-kit

UI этого проекта — на дизайн-ките cosmos-kit (папка `{kit}/`, настройки — `cosmos.json`).
Любая задача про интерфейс — по навыку `cosmos-site` (`.agents/skills/cosmos-site/SKILL.md`): сам, до конца, без вопросов.

- Где мы и что дальше: `python3 {kit}/tools/cosmos.py status`
- Готовая разметка: `{kit}/blocks/INDEX.md`. Классы/токены/иконки: `python3 {kit}/tools/check.py --classes|--tokens|--icons <слово>`
- Проверка: `python3 {kit}/tools/check.py`. Сдача — только после `python3 {kit}/tools/cosmos.py done` = OK.
- Перед сдачей — чеклист опыта `.agents/skills/cosmos-site/references/lessons.md` (грабли классов, пороги, тексты, клавиатура).
- `{kit}/` не правится (обновление: `python3 {kit}/tools/cosmos.py update`). Своё — в своих стилях, только на токенах.
