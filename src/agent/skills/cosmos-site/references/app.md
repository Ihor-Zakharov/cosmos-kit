# Сцена в приложении и темп

Для сайтов-приложений (кабинет, инструмент, экраны данных).

## Сцена в приложении и темп (решение 28.09, DESIGN-TODO п. 17)

Сайт-приложение с экранами текста и данных — не лендинг: звезда не должна мешать читать. Настроение — спокойный
эмбиент, как музыка для сна: мало эффектов, длинные мягкие переходы. Эталон — демо кита.

1. **Главный экран — как демо:** композиция «витрина» (дыра справа, колонка текста слева на датуме), настройки сцены
   кита по умолчанию (текстура ESRGAN `plate-hd.webp`, хаотичный ореол, без лучей RTX), экспозиция −14 % (`.shade` .14).
   Колонка текста — на левом датуме, как в «выдре». Это единственный живой экран. Открытая карточка стоит на том же
   датуме и растёт до кольца, но не заходит на него (на широком окне — две колонки); если окно узкое и карточка легла бы
   на кольцо — сцена уходит в тёмное состояние, как на остальных экранах.
2. **Остальные экраны — «ось» + «за горизонтом»:** дыра переезжает в центр, `setScroll(1)` гасит кадр до ~8 % и ставит
   рендер на паузу — тот самый тёмный фон демо при прокрутке. Без блюра.
3. **Это единственное движение сцены.** Одна пружина в духе Apple — `response` 1,2 с, `damping` 0,85: уверенный старт,
   длинная мягкая посадка и едва заметное «дохождение» (перелёт < 1 %). Путь и свет разведены: уходя с главного, дыра
   сначала заметно едет (первые ~40 % пути), потом гаснет; возвращаясь — сначала светлеет (первые ~55 %), потом едет.
4. **Поиск — оверлей сверху** в колонке своей страницы (на главном — в колонке героя, чтобы не закрыть дыру), страница под
   ним гаснет, сцена — только плоское затемнение (`.shade` .42): дыра не двигается, пульса нет. Esc сначала стирает
   запрос, второй Esc закрывает. Встраивать выдачу в героя нельзя — растущий список сдвигает заголовок.
5. **Одна анимация-событие:** завершённое действие пользователя (сохранил) — вздох энергии и мягкий `spin`, без толчка.
   Старты процессов, наведение, навигация и таймеры — тихие.
6. **Свет — белый.** `data-accent` сайта — `white`, дым нейтральный. Золото — только пока человек пишет отзыв: дым —
   пресет кита «тёплый» (`setSmoke('warm')`, при оценке ≤ 3 — «угольный»), поле текста светится золотом; шкала оценки
   отвечает ступенями (угли — промах, золото — середина, белое — хорошо). Холодные ступени (`violet`, `ice`) не используются.
7. **Темп UI:** `--t-fast` ≥ .25 с, `--t-base` ≥ .4 с, пружины появления без перелёта, кнопки не подпрыгивают на наведение,
   «раскалённое» на экране одно.
