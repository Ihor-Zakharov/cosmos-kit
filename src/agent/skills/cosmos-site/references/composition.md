# Композиция, тон, излучение

Правила вкуса. Это не рекомендации, а ограничения языка; машинно проверяемая часть — в `check.py --rules`.

## Какие токены и компоненты брать

- **Цвет.** Только `--el-a`/`--el-b` (излучение) несут цвет. Все поверхности (`--s1`…`--s4`, `--ink*`,
  `--line*`) монохромны — не нарушайте это точечной подкраской карточек/фонов.
- **Акценты — ось температуры.** `data-accent="violet|ice|white|gold|ember"` на `<html>`; по умолчанию
  белое. Один сайт — одна ступень (бренд), либо ступень как состояние (лёд — покой, белое — норма,
  золото — внимание, угли — горячо), либо как раздел (не больше четырёх равноправных). На одном экране
  не больше двух ступеней, одна из них — белая. При смене ступени перекрашивайте и сцену:
  `api.setAccent(getComputedStyle(document.documentElement).getPropertyValue('--el-a').trim())`.
  Новую ступень или другой цвет не добавляйте — сначала пункт в `DESIGN-TODO.md`.
- **Компоненты** — из `components.css` по классам: `.btn`/`.chip-btn`/`.icon-btn`, `.field`,
  `.tabs`/`.pills` + `.tab-ink`/`.pill-ink`, `.switch`, `.card` (+ `.card.static` для контента),
  `.tree-nav`/`.tnode`, `.crumbs`, `.tag`/`.chip`, `.pager`, `.meter`, `dialog`/`.drawer`/`.modal`,
  `.toasts`, `.ctx`, `.empty`/`.skel`; каркас: `.topbar`/`.island`, `.hero`, `.section`, `.site-footer`,
  `.kicker`, `.display`, `.lead`, `.grid-3`, `.prose`. Разметка — в `demo/index.html`.
- **Не изобретайте новые классы поверх существующих имён.** Нет нужного компонента — соберите из
  токенов или спроектируйте явно и добавьте в кит отдельным проходом с пунктом в `DESIGN-TODO.md`.

## Композиция и тон

Правила вкуса, которые агент соблюдает, собирая новый сайт. Это не рекомендации, а ограничения языка;
если сайт «требует» их нарушить — это повод для нового пункта в `DESIGN-TODO.md`, а не для исключения.

### Иерархия

- **Всё по центру, кроме героя.** Головы секций (`.section-head`), колонки текста, сетки, подвал — центрированы
  по умолчанию; герой — единственное, что стоит на левом датуме (композиция «ось» центрирует и его). Исключения,
  где содержимое остаётся левым **внутри центрированной колонки** (`.centered`): длинный текст статьи (`.prose`),
  таблицы, формы с подписями, дерево/крошки/списки файлов — всё, что читается слева направо построчно. Голова секции
  слева (`.section-head.left`) — только по острой необходимости: рядом с сайдбаром или в приложении с постоянной
  боковой панелью.
- **Один датум.** Левая линия `--datum` задаёт поля; бренд в шапке и герой стоят на ней, остальное центрируется
  в тех же полях.
- **Три уровня чернил, не больше.** `--ink` — заголовки и главное; `--ink-2` — текст; `--ink-3` — кикеры,
  подписи, мета. Четвёртого уровня нет: если что-то «ещё тише», его не должно быть на экране.
- **Роли шрифтов жёсткие.** Geologica — только заголовки (`.display`, `h2`, `.card-title`); Onest — весь
  текст и кнопки; JetBrains Mono — кикеры, числа, метки, код; Unbounded — только имя бренда. Заголовок
  не бывает в Onest, абзац — в Geologica.
- **Одна дыра, один заголовок, одно раскалённое действие.** На экране один `.display`/`h1`, одна
  `.btn.primary` (или `.go-btn`). Второе действие — обычная плита. Кнопка в навигации — плита, не primary.
- **Один индикатор активного состояния на элемент.** Активный пункт показывает либо плашка (`.tab-ink`/`.pill-ink`/
  `.tree-ink`), либо полоска излучения (`.nav-ink` в «линии»), либо цвет — никогда два сразу. Где есть плашка,
  подчёркивания нет.
- **Красная плита — только для необратимого.** `.btn.solid.danger` (и `.chip-btn.solid`) ставится только внутри
  подтверждения разрушительного действия, которое нельзя отменить (удалить навсегда, стереть историю), и никогда
  в общем ряду кнопок. Само действие в интерфейсе — обычная `.btn` с честным текстом («Удалить проект…»);
  опасность передают текст и шаг подтверждения, а не цвет.
- **Заголовки — утверждения.** Кикер моно называет раздел одним-двумя словами, заголовок говорит фразой
  («Одна ось — температура»), абзац объясняет. Заголовок из существительного («Возможности») — слабо.

### Ритм

- **Секции — 96px сверху и снизу** (телефон 64), соседние секции делят один отступ (`.section + .section`).
  Внутри секции шкала 8 / 16 / 24 / 40: кикер→заголовок 12, заголовок→абзац 12, голова→содержимое 40.
- **Герой — весь первый экран** (`100svh`), контент по вертикали в середине; композиция «далеко» — 64svh.
  Ниже героя сразу контент, не второй герой.
- **Одна ширина текста.** Заголовок и абзац секции — до 640px; `.lead` — 560; `.prose` — 640. Сетки
  (`.grid-3`, каталог) — на всю ширину контейнера. Текст на всю ширину экрана (1920, 2560) — ошибка.
- **Плиты не вкладываются глубже двух уровней**: плита (`.card`) → вложенный глиф/чип. Карточка в карточке
  в панели — нет.
- **Подвал тихий.** Волосяная линия сверху, бренд с одной строкой, колонки ссылок `--ink-2`, нижняя строка
  моно `--ink-3`. Никаких плит, кнопок и излучения в подвале.

### Где излучение уместно, где нет

- **Уместно** (и только там): кайма и глиф поля ввода; фокус; заливка прогресса и `live-dot`; кайма
  включённый `.switch`; полоска активного пункта навигации (1px); одно
  «освещённое» слово заголовка `.display .lit`; свечение `.btn.primary` (белое); оттенок тумана сцены.
- **Неуместно:** фоны и плиты любого размера; текст длиннее одного слова; иконки в навигации и в списках;
  разделители (они — `--line-*`, белые с прозрачностью); подвал; декоративные градиенты; тени
  (тени — только глубина, без цвета). «Разукрасить, чтобы оживить» — не приём этого языка.
- **Семантические цвета** (`--ok`, `--warn`, `--err`) — только в тостах, опасных кнопках и статусах, никогда
  как акцент или украшение.
- **Плиты над сценой** (`.glass`, `.tabs`, `.island`, `.topbar.solid`) — `--plate` с волосяной рамкой;
  «стекла» с сильным блюром и бликами нет. Блюр подложки — только у `.topbar.solid`, `.island` и `dialog::backdrop`.


## Правила

- **Свечение используется всегда, но по умолчанию едва заметно.** У сцены всегда есть оттенок дыма: по умолчанию
  `SMOKE_DEFAULT` (лунный, ~45 % силы палитры) включается сам, `createCosmos` делает это без вызова. Сайт без
  свечения — ошибка; ярче оттенок становится только как отклик на процесс или контекст (как цвет платформы в «выдре»),
  и потом возвращается к едва заметному. Нейтральный дым (`opts.smoke: null`) — только осознанно.
- **Ореол по умолчанию — хаотичный** (`halo: 'chaotic'`), лучи RTX выключены. Спокойный ореол — для страниц, где
  сцена должна быть совсем тихой.

- Тёмная тема — чёрная дыра. Светлая — не сейчас (см. выше).
- Монохромные поверхности, цвет только в излучении.
- Одно «раскалённое» действие на экран.
- `prefers-reduced-motion: reduce` не отключать.
- Русские комментарии в коде кита — сохраняйте стиль при добавлении своего кода рядом.
