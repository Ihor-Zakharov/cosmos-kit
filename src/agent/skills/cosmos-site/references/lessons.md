# Опыт и грабли — чеклист перед сдачей

Всё, что кит узнал на живых проверках (abook, выдра, 28.09–01.10.2026) и из базы знаний site-research, одним списком:
правило → порог → «плохо → хорошо». Написано так, чтобы работало у любой модели: не читай кит, читай это.
Что помечено кодом (H11, T1…), ловит линтер `check.py`; остальное — глазами, по этому списку.

## 1. Классы кита, на которых спотыкаются

| грабли | код | плохо → хорошо |
|---|---|---|
| `.empty` — это блок пустого состояния (глиф, `<p>`, `<small>`, кнопка), а не «скрыть» | H11 | `<div class="empty">` для прятания → `[hidden]`; своё — `js-…` или класс в `site.css` |
| `.in` растянут на 100 % колонки — в ряду фильтров селект из трёх слов на 400 px выглядит пустым | H12 | `<select class="in">` в `.btn-row` → `<select class="in auto">` |
| эмодзи в кнопке, заголовке, чипе | H6 | `🔥 жарко` → `<svg><use href="kit/icons/sprite.svg#i-…"/></svg>жарко` или просто текст |
| `outline: none` у поля — фокус пропал | S9 | снимать кольцо только у поля внутри контейнера и давать контейнеру `:focus-within { border-color: var(--line-3) }` (как `.composer-box`) |
| две главные кнопки на экране | H1 | `.btn.primary` + `.btn.primary` → одна `.primary`, вторая `.btn`, третья — ссылка |
| красная кнопка в ряду | H3 | «Удалить» красным в списке → `.btn` с честным текстом, красная `.btn.solid.danger` только в `<dialog>` подтверждения; обратимое — без подтверждения, «Отменить» в тосте |
| `.hero-actions` вне героя — кнопки уезжают влево | H9 | в секции → `.btn-row.row-center` |
| шапка сайта и каркас приложения вместе | H10 | либо `.topbar` + `.hero/.section`, либо `.app` + `.rail` |
| свои цвета, шрифты, `@keyframes`, длительности | S1–S3 | `#fff`, `0.25s` → `var(--ink)`, `var(--t-fast)`; движение — `enter/exit`, `attach*` |
| `alert()` / `confirm()` | J1 | → `site.toast('ok', '…')`, `<dialog class="modal">` через `data-open` |
| сегменты не переключаются | — | `.pills` / `.tabs` без JS → атрибут `data-segmented` (bootSite подхватит) или `wireSegmented` |

| страница прокручивается вместе с лентой чата | — | прокручивается только `.chat-scroll`; поле — последний ряд `.chat-main`, не `position: fixed` |

## 2. Пороги (UX.md — полный текст с источниками)

- Варианты выбора: до 24 на широком экране (16 на узком) — всё видно, без «ещё»; `.choice.more` только для списков длиннее. Фильтры — одним рядом.
- Мастер: ≤ 7 шагов, строка шагов `.steps` от края до края, действия и «✓ сохранено · 14:32» — последний ряд карточки, ничего поверх полей.
- Выпадающий список — только для 5–10 вариантов; меньше — чипы/радио, больше — поле с подсказками (≤ 8 подсказок, задержка 60–120 мс).
- Отклик: ≤ 0,1 с — мгновенно; от 1 с — индикатор (`.meter.indet`, `buttonState('busy')`); от 10 с — фаза словами, таймер, «Отменить», можно уйти с экрана. INP ≤ 200 мс, синхронный JS по клику ≤ 50 мс.
- Движение: UI-переходы ≤ 300 мс (подсказка 125, меню/диалог 180–300); только `transform`/`opacity`; вход — быстрый старт с замедлением; частое (поток, фильтры) — без анимации; `prefers-reduced-motion` — сдвиги → opacity.
- Чернила по APCA: абзацы Lc ≥ 75 (кит: `--ink-2` 78), подписи ≥ 60 (`--ink-3` 62), заголовки ≤ 90 (`--ink` 90). Рамки полей и иконки ≥ 3 : 1 (`--line-3`). `kit/tools/contrast.py`.
- Текст ≥ 14 px (подписи 13), строка 45–75 знаков, межстрочный 1,4–1,6; мелкий моно-капс — только числа и коды.
- Цели нажатия ≥ 24 px, главные 40–44 px; фокус виден всегда и ничем не перекрыт (тосты внизу по центру, поле чата выше них).
- Экран пользователя: 2560×945 и 1920×945 — проверять снимками обеих ширин; телефон 390 — вторым, но обязателен.
- Любая отметка (реакция, «читал», «в очереди») снимается повторным нажатием. Одно действие до результата («в Telegram» сам скачивает → проверяет → отправляет).
- Пустое не показывать: панели результата не рисуются до первого результата; подсказка пустого списка — под фильтрами, с действием.

## 4. Сцена WebGL (что уже в ките — и что не трогать)

- Бюджет кадра: холст 0,5 от CSS-px, DPR ≤ 1, потолок 1,1 Мпикс; в покое 30 fps, 60 — только пока что-то меняется. Не поднимать `resScale` ради «чёткости».
- `powerPreference: 'low-power'`, свёрнутая вкладка — rAF стоит, за героем — рендер на паузе (`attachSceneScroll`), в приложении — спит (`.asleep`).
- Нет WebGL → CSS-кольцо на том же месте (`.cosmos-fallback`, класс `.fallback`); `prefers-reduced-motion` → один статичный кадр, без параллакса.
- Сцена декоративна — `aria-hidden="true"` на обёртке; если канвас когда-нибудь покажет данные, рядом нужен DOM-двойник для скринридера.
- Одна сцена на сайт, под всем, `position: fixed`. Вторую в подвал или секцию — нельзя.

## 5. Мелочи, которые решают

- Цвета шагов — через `color-mix(in oklab, …)`, не `hsl`-сдвиги: перцептивно ровно, в тёмных крайних значениях насыщенность ниже.
- Шрифты кита рисованы с кириллицей (Geologica, Onest, Unbounded, JetBrains Mono); чужие шрифты не подключать (P5) — курсив у «латинских» наборов на кириллице будет программным наклоном.
- Свои SVG — через SVGO (`cosmos.py setup --tools` ставит); в спрайт кита не добавлять, свои иконки — отдельным файлом в проекте.
- Звуки интерфейса (если есть) — только opt-in, с кнопкой «без звука», состояние — в `localStorage`.
- Всё, что перетаскивается (порядок строк, шторка, ползунок), делается и кликом: кнопки ↑↓, крестик, клик по шторке.
- Курсор системный; свой курсор — только как дополнение и никогда вместо системного (пользователь мог увеличить его ради доступности).
- Зерно — статичный `feTurbulence` в CSS (уже в ките), не JS и не PNG.
- Автотесты доступности ловят 30–40 %: перед сдачей пройти экран клавиатурой — Tab по порядку, фокус виден, Esc закрывает, Enter/Space нажимают.
- Снимки: `shot.mjs --w 2560,1920 --h 945` + `--w 390`; `--at #id` — снимок от нужной секции, `--full` — вся страница.
